# 🎬 Grupo: Multimedia / Meta

## 🎥 remotion (video)
**EN** — Make videos programmatically with React components: animations, captions, data-driven or batch
video (e.g. a yearly recap), tutorials. Good for: producing video from code/data. Cortex reaches for it when
you ask to generate or automate a video. **Depends on:** Node/React tooling in the project.
**ES** — Crear videos por código con componentes React: animaciones, subtítulos, video data-driven o por
lote (ej. un resumen anual), tutoriales. Bueno para: producir video desde código/datos. Cortex lo toma
cuando pides generar o automatizar un video. **Depende de:** herramientas Node/React en el proyecto.

## 🧩 skill-creator
**EN** — Create, edit and optimize your own skills (and test/benchmark them). Good for: when you find
yourself repeating a workflow and want to teach it to Cortex once. Cortex suggests it when a task recurs
enough to be worth packaging. **Depends on:** nothing.
**ES** — Crear, editar y optimizar tus propios skills (y probarlos/medirlos). Bueno para: cuando repites un
flujo y quieres enseñárselo a Cortex una vez. Cortex lo sugiere cuando una tarea se repite lo suficiente
como para empaquetarla. **Depende de:** nada.

## 🧠 consolidate-memory
**EN** — Reflective pass over your memory: merges duplicates, fixes stale facts, prunes the index. Good for:
housekeeping when memory grows. Cortex suggests it when it notices duplicated or outdated notes.
**Depends on:** the core memory.
**ES** — Pasada reflexiva sobre tu memoria: fusiona duplicados, corrige datos viejos, poda el índice. Bueno
para: mantenimiento cuando la memoria crece. Cortex lo sugiere cuando detecta notas duplicadas o
desactualizadas. **Depende de:** la memoria del núcleo.
