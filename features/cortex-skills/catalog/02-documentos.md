# 📄 Grupo: Documentos

## 📝 docx
**EN** — Create, read and edit Word documents (reports, letters, templates, letterheads, tables of
contents). Cortex reaches for it whenever a `.docx` is the input or the deliverable. **Depends on:** nothing.
**ES** — Crear, leer y editar documentos Word (informes, cartas, plantillas, membretes, índices). Cortex lo
toma cuando un `.docx` es la entrada o el entregable. **Depende de:** nada.

## 📑 pdf
**EN** — Read, merge, split, fill, extract, and create PDFs (incl. OCR on scans). Cortex reaches for it
whenever a `.pdf` is involved. **Depends on:** nothing.
**ES** — Leer, unir, dividir, rellenar, extraer y crear PDFs (incl. OCR de escaneos). Cortex lo toma cuando
hay un `.pdf` de por medio. **Depende de:** nada.

## 📊 pptx
**EN** — Create and edit slide decks / presentations (and read `.potx` templates, notes, comments). Cortex
reaches for it whenever a deck or `.pptx` is the input or deliverable. **Depends on:** nothing.
**ES** — Crear y editar presentaciones / decks (y leer plantillas `.potx`, notas, comentarios). Cortex lo
toma cuando un deck o `.pptx` es la entrada o el entregable. **Depende de:** nada.

## 📈 xlsx
**EN** — Open, clean, edit and build spreadsheets (formulas, formatting, charts) — `.xlsx`, `.csv`. Cortex
reaches for it when a spreadsheet is the main input or output. **Depends on:** nothing.
**ES** — Abrir, limpiar, editar y construir planillas (fórmulas, formato, gráficos) — `.xlsx`, `.csv`.
Cortex lo toma cuando una planilla es la entrada o salida principal. **Depende de:** nada.
