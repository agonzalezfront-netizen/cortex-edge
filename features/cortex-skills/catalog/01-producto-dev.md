# 🛠️ Grupo: Producto / Dev

## ⚡ superpowers
**EN** — Discipline pack: brainstorming, TDD, systematic debugging, writing plans, code review.
Good for: building or fixing anything non-trivial, keeping it rigorous. Cortex reaches for it on its own on
a real bug (*debugging*), a new feature (*brainstorm* → *plan*), writing code (*TDD*). Won't force it on a
one-line fix or a question. **Depends on:** nothing.
**ES** — Pack de disciplinas: brainstorming, TDD, depuración sistemática, escritura de planes, revisión de
código. Bueno para: construir o arreglar algo no trivial, con rigor. Cortex lo toma solo ante un bug real
(*debugging*), una feature nueva (*brainstorm* → *plan*), al escribir código (*TDD*). No lo fuerza en un
arreglo de una línea o una pregunta. **Depende de:** nada.

## 🎨 frontend-design
**EN** — Builds distinctive, production-grade UIs that avoid the generic "AI-made" look. Good for:
landing pages, app screens, components you want to feel crafted. Cortex reaches for it when you ask to
build or design a web interface. Won't use it for backend or non-visual work. **Depends on:** nothing.
**ES** — Crea interfaces distintivas, de nivel producción, que evitan el look genérico "hecho por IA".
Bueno para: landing pages, pantallas de app, componentes que quieras que se sientan cuidados. Cortex lo
toma cuando pides construir o diseñar una interfaz web. No lo usa para backend o trabajo no visual.
**Depende de:** nada.

## 🧭 ui-ux-pro-max
**EN** — UI/UX intelligence: 67 styles, palettes, font pairings, chart types, and stack-specific guidance
(React, Vue, Tailwind, shadcn…). Good for: planning look-and-feel, choosing colors/typography, reviewing UI.
Cortex reaches for it when you design or critique an interface's style. **Depends on:** nothing.
**ES** — Inteligencia UI/UX: 67 estilos, paletas, pares tipográficos, tipos de gráfico y guía por stack
(React, Vue, Tailwind, shadcn…). Bueno para: planear el look-and-feel, elegir colores/tipografía, revisar
UI. Cortex lo toma cuando diseñas o criticas el estilo de una interfaz. **Depende de:** nada.
