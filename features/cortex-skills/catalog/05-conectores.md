# 🔌 Grupo: Conectores (requieren conectar una cuenta)

> ⚠️ **These need an external account/MCP connected** to work. Cortex will say so and won't pretend they
> work until you connect them. / **Necesitan una cuenta/MCP externa conectada** para funcionar. Cortex lo
> dice y no finge que funcionan hasta que las conectes.

## 🗂️ Google Workspace (Gmail · Drive · Calendar)
**EN** — Read/search email, work with Drive files, manage the calendar. Good for: turning "handle my inbox /
find that doc / schedule this" into action. **Depends on:** a connected Google account (MCP).
**ES** — Leer/buscar correo, trabajar con archivos de Drive, gestionar el calendario. Bueno para: convertir
"revisa mi correo / busca ese documento / agenda esto" en acción. **Depende de:** una cuenta de Google
conectada (MCP).

## 🎨 Figma
**EN** — Read designs from Figma into code and push code into Figma (design ↔ code). Good for: implementing
a Figma file or keeping design and code in sync. **Depends on:** a connected Figma account (MCP).
**ES** — Leer diseños de Figma a código y llevar código a Figma (diseño ↔ código). Bueno para: implementar
un archivo de Figma o mantener diseño y código sincronizados. **Depende de:** una cuenta de Figma conectada (MCP).

## 📣 Marketing / Sales (Notion, HubSpot, Slack, Salesforce…)
**EN** — Work directly with your business tools: notes/databases (Notion), CRM (HubSpot/Salesforce),
messaging (Slack), and more. Good for: teams already running on those tools. **Depends on:** each tool's
account connected (MCP), one per tool.
**ES** — Trabajar directo con tus herramientas de negocio: notas/bases (Notion), CRM (HubSpot/Salesforce),
mensajería (Slack) y más. Bueno para: equipos que ya usan esas herramientas. **Depende de:** la cuenta de
cada herramienta conectada (MCP), una por herramienta.
