# 🔎 Grupo: Investigación / Datos

## 🌐 deep-research
**EN** — Multi-source, fact-checked research reports: fans out web searches, reads sources, verifies claims,
synthesizes with citations. Good for: understanding a market, a competitor, a topic in depth. Cortex reaches
for it when you ask a real research question (not a quick fact). **Depends on:** nothing (uses web search).
**ES** — Informes de investigación multi-fuente y verificados: abre búsquedas web, lee fuentes, verifica
afirmaciones y sintetiza con citas. Bueno para: entender un mercado, un competidor, un tema a fondo. Cortex
lo toma cuando haces una pregunta de investigación real (no un dato rápido). **Depende de:** nada (usa web).

## 📊 dataviz
**EN** — Charts, dashboards and data visualizations that read as one system (light/dark, accessible). Good
for: turning numbers into clear visuals. Cortex reaches for it before writing any chart code or building a
dashboard/KPI tile. **Depends on:** nothing.
**ES** — Gráficos, dashboards y visualizaciones que se leen como un sistema (claro/oscuro, accesibles).
Bueno para: convertir números en visuales claros. Cortex lo toma antes de escribir código de gráficos o
armar un dashboard/tarjeta de KPI. **Depende de:** nada.
