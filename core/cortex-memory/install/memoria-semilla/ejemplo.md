**EN.** This is a sample memory note. Delete it once you have real ones. A note holds one fact or decision;
for a decision, add the **why**. Link related notes with [[their-name]]. The one-line summary in `MEMORY.md`
is what your Claude scans to decide relevance.

**ES.** Esta es una nota de memoria de ejemplo. Bórrala cuando tengas notas reales. Una nota guarda un hecho
o decisión; si es una decisión, agrega el **porqué**. Enlaza notas relacionadas con [[nombre-de-otra]]. El
resumen de una línea en `MEMORY.md` es lo que tu Claude revisa para decidir relevancia.
